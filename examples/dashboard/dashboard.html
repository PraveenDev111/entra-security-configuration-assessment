About this assessment. SecureIT Identity checks a Microsoft Entra ID tenant using read-only Microsoft Graph data. The checks are automated configuration tests adapted from open source projects, plus SecureIT's own checks. Results are a starting point and should be reviewed by an engineer before any change is made.

  • Maester (MIT licence, © Maester Team): test logic, descriptions and remediation text, including the EIDSCA configuration tests (maester.dev).
  • Microsoft Zero Trust Assessment (MIT licence): identity tests, descriptions and remediation text.
  • CISA SCuBA / ScubaGear (CC0 1.0, public domain): Entra ID baseline controls.
  • Remediation links point to Microsoft Learn.

The projects above are not affiliated with SecureIT or Jolera and do not endorse these results. Sign-in, audit and provisioning charts use logs from the Event Hub integrations, not this tool. Data stays in your browser.
